# Word Counter

Демонстраційна **навичка-пакет** каталогу: архів зі `skill.md` та кодом,
який завантажують із бази знань і запускають у власному середовищі
(локально або у своєму агентному інструменті).

## Як запустити

```bash
echo '{"inputs": {"text": "Привіт, світ!"}}' | python main.py
```

Необов'язкові параметри в `inputs`:
- `uppercase` — будь-яке значення додає до звіту текст у ВЕРХНЬОМУ регістрі;
- `save_report` — будь-яке значення створює поруч файл `report.txt`.

## Контракт
- На `stdin` надходить JSON виду `{"inputs": {...}}`.
- У `stdout` виводиться JSON `{"output": "..."}`.

Допоміжна логіка винесена в `lib/counter.py` — приклад того, що пакет може
містити вкладені файли й папки.
